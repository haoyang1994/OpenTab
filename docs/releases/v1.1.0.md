# OpenTab 1.1.0

Open-source under Apache License 2.0. No new Chrome permissions. Includes test/CI hardening, vendored browser libraries, and SSH gateway authentication already landed on `master`.

## English

### License

- The project is licensed under **Apache License 2.0**.
- Third-party software, photos, trademarks, and the FIX dictionary are described in [`NOTICE`](../../NOTICE).
- Some items in `NOTICE` are **not** Apache-2.0 (Pexels photos, third-party trademarks, the QuickFIX/J-derived FIX dictionary, and icons pending a later replacement PR). The Pexels stills and those icons were replaced in [PR #6](https://github.com/haoyang1994/OpenTab/pull/6).

### Added

- `LICENSE`, `NOTICE`
- Bilingual README, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `CHANGELOG.md`
- GitHub issue / pull request templates
- `CI` workflow (`.github/workflows/ci.yml`) that runs `npm test`
- Repository hygiene checks in `npm test`
- This release note

### Changed

- Loading the unpacked extension does not need `npm install`: calendar and terminal files live in `vendor/` (#2). `npm install` is still required to run tests or the local SSH gateway.
- `npm test` works on Linux without a display and is the same command CI runs (#1).
- SSH gateway: set `SSH_GATEWAY_EXTENSION_ID` (required Origin allowlist) and an access token (`SSH_GATEWAY_TOKEN` or the generated file). `SSH_PRIVATE_KEY_PATH` is optional and explicit; the gateway does not fall back to `~/.ssh/id_rsa` (#3).

### Security

- Gateway connections must come from this extension and present a token. Compress arguments are POSIX-quoted. See README.

### Removed

- Unreferenced files: `FIX50SP2.xml`, `fix_values.js`, `fix_tags_new.js`, `test.mjs`
- `SPEC.md` moved to `docs/SPEC.md` (historical; may not match the current product)

### Unchanged

- `permissions`, `host_permissions`, and `content_security_policy` in `manifest.json`

### Known issues (to be fixed in later iterations)

- SSH passwords are stored in `chrome.storage.local` as plaintext

This release does **not** create a `v1.1.0` git tag or a GitHub Release. The `v1.0.0` tag already exists.

### 许可

- 本项目以 **Apache License 2.0** 开源。
- 第三方软件、照片、商标和 FIX 字典见 [`NOTICE`](../../NOTICE)。
- `NOTICE` 中部分条目**不在** Apache-2.0 授权范围内（Pexels 照片、第三方商标、源自 QuickFIX/J 的 FIX 字典、以及将另开 PR 替换的图标）。这些 Pexels 静图和旧图标已在 [PR #6](https://github.com/haoyang1994/OpenTab/pull/6) 替换。

### 新增

- `LICENSE`、`NOTICE`
- 双语 README，以及 `CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`SECURITY.md`、`CHANGELOG.md`
- GitHub Issue / Pull Request 模板
- 执行 `npm test` 的 `CI` workflow
- 仓库规范检查（随 `npm test` 运行）
- 本发布说明

### 变更

- 加载已解压扩展**不需要** `npm install`：日历和终端文件在 `vendor/`（#2）。跑测试或启动本地 SSH 网关仍然需要 `npm install`。
- `npm test` 在无显示器 Linux 与 CI 上可直接跑（#1）。
- SSH 网关必须设置 `SSH_GATEWAY_EXTENSION_ID`（Origin 白名单）和访问令牌（`SSH_GATEWAY_TOKEN` 或生成的文件）。`SSH_PRIVATE_KEY_PATH` 为显式可选；不设置时不会回落到 `~/.ssh/id_rsa`（#3）。

### 安全

- 网关只接受本扩展连接，并校验 token。compress 参数经 POSIX 单引号转义。详见 README。

### 删除

- 未被引用的 `FIX50SP2.xml`、`fix_values.js`、`fix_tags_new.js`、`test.mjs`
- `SPEC.md` 移至 `docs/SPEC.md`（历史设计文档，可能与现状不一致）

### 未改动

- `manifest.json` 中的权限、host 权限和 CSP

### 已知问题（后续迭代修复）

- SSH 密码目前以明文保存在 `chrome.storage.local`

本版本**不**创建 `v1.1.0` git tag，也**不**发布 GitHub Release。`v1.0.0` tag 已经存在。
