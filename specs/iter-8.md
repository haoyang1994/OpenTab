# 迭代 8 图标质量与隐私（一屏需求）
目标：图标清晰好看，打开新标签页时不再向所有网站发请求。新逻辑放 icons.js。
- AC1 新增快捷方式时按顺序取图标：内置高清图标库命中 → 站点的 apple-touch-icon → `/favicon.ico` 或 manifest 图标 → 带底色的首字母占位（颜色由域名决定、风格统一）。取到的图标转成本地 data URL（压到 ≤128px、≤20KB）存起来，以后打开新标签页零网络请求。
- AC2 内置高清图标库至少覆盖 40 个常用站点（中文和国际各半，如百度、淘宝、京东、B站、知乎、微博、GitHub、YouTube、Gmail……），矢量或 128px PNG，许可证兼容 Apache-2.0，写进 NOTICE；商标说明沿用 NOTICE 现有条款。
- AC3 老用户升级：后台空闲时（requestIdleCallback）逐个把现有远程图标转成本地缓存，失败的保留原样，不阻塞首屏。
- AC4 右键「更换图标」：重新抓取、上传本地图片、选首字母占位并改颜色。
- AC5 隐私：E2E 断言首屏加载期间对第三方站点的图标请求为 0（只允许 bing.com 和 wttr.in 等已声明的请求）。
- AC6 `npm test` 覆盖 AC1–AC5 并全部通过；不新增权限；包体增量不超过 300KB；首屏不劣化。
